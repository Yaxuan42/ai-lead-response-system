# AI Revenue Response Desk

Bilingual static sales page for a horizontal AI lead-to-revenue service.

Default language: Chinese. The header switch previews English.

## Route

This is the open-market route. It does not lock to one target customer category. It qualifies prospects by economics:

- High deal value.
- Existing inquiry source.
- Slow or inconsistent first response.
- Clear owner or sales follow-up.
- Measurable 7-day pilot.

## What It Sells

An implementation service for any high-value inquiry workflow:

- Connect one or more lead sources.
- Reply to new inquiries quickly.
- Qualify budget, timing, role, and need.
- Alert the owner or sales lead for high-intent opportunities.
- Keep a follow-up queue for funnel review.

The contact form opens an email to `hello@yaxuan.space`.
